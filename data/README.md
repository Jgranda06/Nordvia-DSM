# Data

The input package: 11 SAP FI tables as CSV, unchanged.

Files:
- T001 (company codes), SKA1, SKAT, SKB1 (chart and company accounts), CSKS (cost centers), KNA1 (customers), LFA1 (vendors), T003 (document types), TBSL (posting keys), BKPF (document headers) and BSEG (line items). Fields are described in [../DATA_DICTIONARY.csv](../DATA_DICTIONARY.csv).
