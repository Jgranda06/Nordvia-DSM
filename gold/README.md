# Gold

One CSV per class of the ontology, ready to be mapped. Generated by `notebooks/03_gold.ipynb` from the silver tables.

Files:
- [accounting_document.csv](accounting_document.csv), [line_item.csv](line_item.csv): documents and their lines.
- [company.csv](company.csv), [controlling_area.csv](controlling_area.csv), [cost_center.csv](cost_center.csv): organization.
- [customer.csv](customer.csv), [payee.csv](payee.csv), [payee_identifier.csv](payee_identifier.csv), [address.csv](address.csv): business partners.
- [chart_of_accounts.csv](chart_of_accounts.csv), [gl_account.csv](gl_account.csv), [company_account.csv](company_account.csv): accounts.
- [document_type.csv](document_type.csv), [posting_key.csv](posting_key.csv): code lists.
- [exchange_rate.csv](exchange_rate.csv): monthly exchange rates to euros, derived from the documents.

**Note**: these files are the input of the mappings. They are included so the graph can be rebuilt without running notebooks 01 to 03.
